# Transcript · 稿

给一个视频链接，拿回一份能慢慢读的文字稿。

转写在这台机器上跑，**音频不上传任何地方**。有现成字幕的视频几秒钟出稿，没有的才下载音频转写一遍。

macOS 原生（Apple 芯片走 Metal），依赖只有 `yt-dlp` 和 `whisper.cpp`，不需要 Python 虚拟环境、不需要账号、不需要联网服务。

---

## 它解决什么

把视频当视频看，就只能被它的节奏牵着走；变成文字，才能跳读、搜索、摘抄、对照、丢给 AI 换视角。

但大多数转写工具要你把整段音频传到别人的服务器上。这个不要——音频和文字全程只在你自己的机器里，断开网络照样能转（前提是视频已经下下来了）。

## 特性

**先找字幕，再谈转写。** 平台上有字幕就只取字幕，不下载音频、不跑模型，几秒钟出稿。中文优先于英文，人工字幕优先于自动生成，弹幕和直播聊天会排除掉。字幕是机翻的时候，可以在设置里关掉「字幕优先」强制走转写。

**多任务排队。** 连贴几个链接不用等，默认同时跑两个——一个在转写，下一个在下载，谁也不等谁。可调 1/2/3。同一条视频不会重复建任务。

**能停下来。** 任务卡片上的 × 立刻停掉：排队中的出队，跑着的在下一次检查点退出，不写半成品进库，不留垃圾文件。

**链接拿不到的时候还有两条路。** 微信视频号、小红书这类媒体地址现签现过期，任何工具都取不到。稿会直接说拿不到，然后给你两个入口：按标题去 B站 / YouTube 搜同版（带封面、时长、播放量），或者把本地文件拖进来转。

**读的时候能做事。** 选中一段文字浮出三个动作：复制、摘抄、问 AI（带着一段「这段话成立的前提是什么、有没有反例、最可能错在哪」的提问框架，粘给任何 AI 都不会附和）。

## 安装

需要 macOS，以及一次性的联网。

### 方式一：直接跑（给普通使用）

1. 下载 [最新的 zip](../../releases/latest)，解压到哪都行。
   （在 GitHub 网页上看这段时链接能直接点；本地看就 `releases/latest`）
2. 双击 **`安装.command`**。
3. 跟着终端窗口里的进度走，三到八分钟。**别关窗口**——编译那一段输出会一直滚，是正常的。
4. 走完回车，以后每次只要双击 **`稿.command`**。

装的东西：`yt-dlp`（下载器，走系统自带的 Python，装到用户目录）、`whisper.cpp`（转写引擎，单个文件）、一个识别模型（约 180 MB）。全程不要密码，不碰系统文件。有 Homebrew 就直接装二进制，没有就从源码编一个，脚本会自己用 pip 装上 cmake。

详细说明和排障见 [`使用说明.md`](使用说明.md)。

### 方式二：装进 Claude（给常用 AI 的人）

[`skill/transcript/SKILL.md`](skill/transcript/SKILL.md) 是一份自包含的 skill：把文件给 Claude 说「装上这个」，之后直接说「把这个视频转成文字」就行。

它和 App 是同一套逻辑——先看字幕，没有才转写——也共用同一个模型目录，装过一次另一条就不用再装。

两种方式挑一个即可。

## 怎么用

双击 `稿.command`，浏览器会打开 `http://127.0.0.1:8765/`。

把链接贴进顶部那一栏，点转写。左边是稿件库和任务队列，右边是正文。

不想用浏览器的时候，也可以直接调 skill 里的 `gz.py`（见 SKILL.md）。

## 能转哪些平台

YouTube、B站、小宇宙，以及 yt-dlp 认得的绝大多数公开视频站。

**取不到的**：微信视频号、小红书、公众号。它们的媒体地址是播放器里现签的，几分钟就过期，程序拿到的是死链——不是配置问题，调不出来。

**时好时坏的**：抖音、TikTok。设置里有「浏览器 Cookie」和「代理」两项是给它们准备的。TikTok 打不开多半是出口 IP 的事，跟 cookie 没关系。

## 数据与隐私

```
~/Library/Application Support/Transcript/
├── whisper/    转写引擎和识别模型
└── items/      你转出来的稿
```

放在这里而不是「稿」文件夹里，所以整个程序目录可以随便挪位置、删掉重装，稿子都还在。

唯一的联网动作：从视频站取视频信息和字幕/音频；第一次安装时从 GitHub 取 whisper.cpp 源码、从 Hugging Face 取模型。**没有任何遥测、没有账号、没有云端。**

## 技术实现

- **界面**：Flask + 一个单页 HTML，没有构建步骤，没有前端框架。
- **下载**：yt-dlp（Python 库方式调用，`--skip-download` 时只取字幕）。
- **转写**：whisper.cpp，`-l auto` 自动判别语言——写死语言去转另一种语言的视频会出乱码，这是最常踩的坑。
- **音频转 wav**：有 ffmpeg 用 ffmpeg，没有就用 macOS 自带的 `afconvert`，所以 ffmpeg 不是必装项。
- **代理**：`socksio` 和 `PySocks` 直接放在 `app/vendor/`，由 `PYTHONPATH` 挂上，不依赖 pip 能不能装上。
- **并发**：每个槽位一个独立模型实例（共用会抢内部线程池），`cpu_threads` 按核数除以并发数分配。

## 常见问题

**macOS 说「无法验证开发者」** → 右键点 `安装.command` → 打开。

**说「已损坏，无法打开」** → 文件被打上了「来自网络」标记。在那个文件夹里打开终端运行：

```bash
xattr -dr com.apple.quarantine .
chmod +x 安装.command 稿.command launch.sh
```

**编译时报 `C++ 头不在默认位置`** → 不是错误。有的机器命令行工具装残了，`CommandLineTools/usr/include/c++/v1` 不存在，脚本会自动改用 SDK 里那份。

**转写报「转 wav 失败」** → 那一源只提供了 afconvert 不认的格式（常见于 webm）。装个 ffmpeg 就彻底解决。

**端口被占** → `TRANSCRIPT_PORT=8800 ./launch.sh`。

## 已知限制

- 只在 macOS 上测过。Linux 上理论上能跑（whisper.cpp 有编译产物），但启动脚本是按 macOS 写的。
- 没有 Windows 版本，也不打算做。
- 不做手机端：iOS 沙盒里跑不了 yt-dlp 和 whisper。
- 界面只有中文，没做多语言。

## 开发

没有构建步骤。改 `app/server.py` 或 `app/static/index.html` 之后，双击 `稿.command` 会先杀掉旧进程再起新的。

```
稿/
├── 安装.command          装机，幂等，可以重复跑
├── 稿.command            日常启动入口
├── launch.sh             找 Python、起 Flask、开浏览器
├── app/
│   ├── server.py         全部后端逻辑
│   ├── static/index.html 整个界面
│   └── vendor/           socksio + PySocks + 兼容补丁
├── skill/transcript/     可装进 Claude 的同款 skill
└── 使用说明.md            写给使用者的详细说明
```
